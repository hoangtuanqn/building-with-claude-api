# Structured Data (dữ liệu có cấu trúc)

Khi bạn cần Claude generate (sinh ra) structured data (dữ liệu có cấu trúc) như JSON, Python code, hay danh sách bullet, bạn sẽ thường gặp phải một vấn đề phổ biến: Claude muốn hữu ích nên thêm text (văn bản) giải thích xung quanh nội dung của bạn. Điều này thường là tốt, nhưng đôi khi bạn chỉ cần raw data (dữ liệu thô), không kèm gì khác.

Hãy tưởng tượng bạn đang xây dựng một web app để generate AWS EventBridge rules (quy tắc). User (người dùng) nhập mô tả, bấm generate, và mong đợi thấy clean JSON (JSON sạch) mà họ có thể copy và dùng ngay. Nếu Claude trả về JSON được bọc trong markdown code block kèm text giải thích, user không thể copy toàn bộ response (phản hồi) một cách đơn giản — họ phải tự tay chọn đúng phần JSON.

## Vấn đề với Default Response (phản hồi mặc định)

Mặc định, khi bạn yêu cầu Claude generate JSON, bạn có thể nhận được kết quả như sau:

````
```json
{
  "source": ["aws.ec2"],
  "detail-type": ["EC2 Instance State-change Notification"],
  "detail": {
    "state": ["running"]
  }
}
```

This rule captures EC2 instance state changes when instances start running.
````

JSON này đúng, nhưng nó bị bọc trong markdown formatting (định dạng markdown) và kèm theo text giải thích. Đối với một web app mà user cần copy raw JSON, điều này tạo ra friction (ma sát, cản trở) trong trải nghiệm sử dụng.

## Giải pháp: Assistant Message Prefilling (mồi trước tin nhắn trợ lý) + Stop Sequences (chuỗi dừng)

Bạn có thể kết hợp assistant message prefilling với stop sequences để lấy chính xác nội dung mình muốn. Cách hoạt động như sau:

```python
messages = []

add_user_message(messages, "Generate a very short event bridge rule as json")
add_assistant_message(messages, "```json")

text = chat(messages, stop_sequences=["```"])
```

Kỹ thuật này hoạt động theo cơ chế:

1. User message cho Claude biết cần generate cái gì
2. Assistant message được prefill (mồi trước) khiến Claude "nghĩ" rằng nó đã bắt đầu một markdown code block rồi
3. Claude tiếp tục bằng cách viết ra nội dung JSON thuần túy
4. Khi Claude cố gắng đóng code block bằng dấu `````, stop sequence lập tức chấm dứt việc generate

Kết quả là một đoạn JSON sạch, không có formatting (định dạng) thừa:

```json
{
  "source": ["aws.ec2"],
  "detail-type": ["EC2 Instance State-change Notification"],
  "detail": {
    "state": ["running"]
  }
}
```

## Xử lý Response

Bạn có thể nhận thấy một số ký tự newline (xuống dòng) thừa trong response. Những ký tự này rất dễ xử lý:

```python
import json

# Dọn dẹp và parse (phân tích) JSON
clean_json = json.loads(text.strip())
```

## Không chỉ dừng lại ở JSON

Kỹ thuật này không chỉ giới hạn ở việc generate JSON. Hãy dùng nó bất cứ khi nào bạn cần structured data mà không kèm commentary (bình luận, giải thích):

* Đoạn code Python
* Danh sách bullet
* Dữ liệu CSV
* Bất kỳ formatted content (nội dung được định dạng) nào mà bạn chỉ muốn lấy content, không cần giải thích

Điểm mấu chốt là xác định xem Claude tự nhiên muốn bọc nội dung của bạn bằng gì, sau đó dùng chính điều đó làm prefill và stop sequence. Với code, thường sẽ là markdown code block. Với danh sách, có thể sẽ là các ký hiệu formatting khác.

Cách tiếp cận này cho bạn khả năng kiểm soát chính xác format (định dạng) output (đầu ra) của Claude, giúp việc tích hợp AI-generated content (nội dung do AI sinh ra) vào các application (ứng dụng) cần clean, structured data trở nên dễ dàng hơn nhiều.
