# Accessing the API

## Tổng quan luồng request

Mỗi request đến Claude đi qua 5 bước: **Client → Server của bạn → Anthropic API → Model xử lý → Trả về Client.**

---

## Tại sao cần server trung gian?

Không được gọi Anthropic API trực tiếp từ client. API key phải được giữ bí mật ở phía server — để lộ ra client là lỗ hổng bảo mật nghiêm trọng.

---

## Các trường bắt buộc trong mỗi request

| Field | Mô tả |
|---|---|
| `api_key` | Xác thực với Anthropic |
| `model` | Model muốn dùng (vd: `claude-sonnet-4-6`) |
| `messages` | Nội dung input của người dùng |
| `max_tokens` | Giới hạn số token được sinh ra |

---

## Bên trong Claude xử lý gì?

1. **Tokenization** — Chia văn bản thành các token (xấp xỉ 1 từ = 1 token)
2. **Embedding** — Chuyển mỗi token thành vector số biểu diễn nghĩa của nó
3. **Contextualization** — Tinh chỉnh nghĩa dựa vào ngữ cảnh xung quanh
4. **Generation** — Tính xác suất từ tiếp theo, kết hợp randomness để sinh ra văn bản tự nhiên

---

## Khi nào Claude dừng sinh?

- Đạt `max_tokens`
- Sinh ra end-of-sequence token (kết thúc tự nhiên)
- Gặp stop sequence được định nghĩa trước

---

## Cấu trúc response trả về

```json
{
  "message": "Nội dung được sinh ra",
  "usage": { "input_tokens": ..., "output_tokens": ... },
  "stop_reason": "end_turn | max_tokens | stop_sequence"
}
```
