Dưới đây là bản tóm tắt hướng dẫn gọi Anthropic API lần đầu bằng Python:

## Setup môi trường

1. Cài package cần thiết:
```
%pip install anthropic python-dotenv
```

2. Tạo file `.env` chứa API key (tránh hardcode key vào code, nhớ thêm `.env` vào `.gitignore`):
```
ANTHROPIC_API_KEY="your-api-key-here"
```

3. Load biến môi trường và khởi tạo client:
```python
from dotenv import load_dotenv
load_dotenv()

from anthropic import Anthropic
client = Anthropic()
model = "claude-sonnet-4-0"
```

## Function chính: `client.messages.create()`

Yêu cầu 3 tham số bắt buộc:
- **model**: tên model Claude sử dụng
- **max_tokens**: giới hạn an toàn cho độ dài response — đây là **cận trên (upper bound)**, không phải target. Claude sẽ tự dừng khi thấy đủ ý, chỉ bị cắt cứng nếu chạm giới hạn này trước.
- **messages**: lịch sử hội thoại gửi cho Claude

## Cấu trúc Messages

Giống chat app, gồm 2 loại role:
- **user**: nội dung do người dùng gửi
- **assistant**: response do Claude sinh ra

Mỗi message là một dict với `role` và `content`.

## Ví dụ request đầy đủ

```python
message = client.messages.create(
    model=model,
    max_tokens=1000,
    messages=[
        {
            "role": "user",
            "content": "What is quantum computing? Answer in one sentence"
        }
    ]
)
```

## Lấy nội dung response

Response trả về là một object chứa nhiều metadata, nhưng phần text thực sự nằm ở:
```python
message.content[0].text
```

---

Note: bài viết dùng model string `claude-sonnet-4-0` — đây có thể là ví dụ minh họa từ tài liệu cũ hoặc naming convention khác, không nằm trong danh sách model hiện tại (Opus 5, Sonnet 5, Haiku 4.5...). Nếu anh triển khai thật, nên check lại model string chính xác trong docs trước khi build production.
